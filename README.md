# Node HTTP Server

A minimal Node.js HTTP server exercise: it serves a form and saves submitted messages.

## About The Project

A small server built with the Node.js `http` module, without any framework. Requests to `/` are served an HTML page with a form; submitting the form sends a POST request to `/message`, whose content is parsed and written to a file.

## Built With

- Node.js

## Getting Started

### Prerequisites

- Node.js

### Running the server

- Start the server with `npm start` (or `npm run dev` to use nodemon).
